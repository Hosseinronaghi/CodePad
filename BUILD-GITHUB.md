# CodePad Android APK build

1. Open https://github.com/Hosseinronaghi/CodePad/actions.
2. Select **Android APK** and click **Run workflow** if available.
3. GitHub Actions also builds on pushes to main.
4. If the build completes successfully, open its **Artifacts** and download `CodePad-debug-apk`.
5. If the build fails, read **Build debug APK** logs first.

The project is an unfinished development version and has not passed end-to-end Android device testing. The debug APK must not be treated as a production release.
